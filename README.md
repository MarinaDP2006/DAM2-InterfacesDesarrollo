# DAM2 - Desarrollo de Interfaces

Prácticas de interfaces de usuario con JavaFX.

##  Contenido
- **ManagerAlumnos/** - CRUD con JavaFX + TableView
- **Otros proyectos JavaFX** - Layouts, CSS, FXML

##  Tecnologías
- Java 21
- JavaFX 21
- Scene Builder
- Maven

##  Cómo ejecutar
Abrir en IntelliJ y ejecutar la clase MainApp.java. Requiere tener configurado JavaFX SDK.
